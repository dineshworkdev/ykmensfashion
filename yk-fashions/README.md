# YK MENS FASHION — Retro & Contemporary Streetwear Studio

A distinctive, retro-inspired, artistic, and friendly e-commerce showcase for **YK MENS FASHION**.

## Features
- **Men's Fashion Only**: Curated 100% men's streetwear photography, boxy blanks, graphic drops, and male apparel.
- **Retro Art-Direction**: Warm solid color blocking (Warm Cream, Butter Yellow, Burnt Orange, Deep Muted Teal, Dusty Blue, Dusty Coral, Soft Sage, Terracotta, Deep Espresso Ink).
- **Moving Fashion Poster Hero**: Multi-layered animated hero with animated SVG path doodles, model card, and live tags.
- **Catchy Color Rhythm**: Striking color blocks across sections (Deep Teal Discovery, Burnt Orange Manifesto, Butter Yellow Collections).
- **Mobile-First Experience**: High-impact mobile hero, touch-friendly retro buttons, and editorial slide-out menu drawer.
- **Frontend E-Commerce Flow**: Cart with free-shipping meter and coupon code, 4-step checkout wizard, interactive size guide modal, instant keyword search, and reactive wishlist.

## Tech Stack
- React 18
- Vite 5
- Tailwind CSS 3
- Framer Motion 11
- React Router 6
